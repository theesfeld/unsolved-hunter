# Unsolved Hunter

Daily attempts at unsolved problems: open conjectures in mathematics, unsolved ciphers, and undeciphered texts. Each day one target is researched and attacked with fresh angles and real code, on free compute only.

## The skeptic gate

Nothing counts as solved until **at least two independent skeptic agents**, each starting from a fresh context and writing their own code, rebuild the result from scratch and sign off that it is (1) correct, (2) new, and (3) actually solves the problem as stated, with no stretched definitions. If any skeptic can't reproduce it, can't confirm novelty, or objects to the framing, it doesn't count.

## Honest caveat

These results are **not externally peer reviewed**. The skeptic gate is an internal check run by independent automated agents, not review by outside mathematicians. Treat every result here as a careful preprint and check it yourself. Corrections and reviews are welcome via issues.
